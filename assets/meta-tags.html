# Meta Tags Template Complete meta tag template for GEO+SEO. Copy into your `` section. --- ## Universal Template ```html [Primary Keyword] — [Secondary Keyword] | [Brand] ``` ## Dynamic Injection by Framework ### React (react-helmet-async) ```jsx import { Helmet } from 'react-helmet-async'; function SEOHead({ page }) { return ( {page.title} | Brand ); } ``` ### Next.js (App Router) ```tsx import type { Metadata } from 'next'; export function generateMetadata({ params }): Metadata { return { title: `${pageTitle} | Brand`, description: pageDescription, openGraph: { title: pageTitle, description: pageDescription, type: 'article', url: `https://yoursite.com/${slug}`, images: [{ url: imageUrl, width: 1200, height: 630 }], publishedTime: publishDate, authors: [authorName], }, twitter: { card: 'summary_large_image', title: pageTitle, description: pageDescription, }, alternates: { canonical: `https://yoursite.com/${slug}`, }, }; } ``` ### WordPress (PHP) ```php <?php wp_title('|', true, 'right'); bloginfo('name'); ?> ``` ### Hugo ```html {{ .Title }} | {{ .Site.Title }} {{ with .Params.image }} {{ end }} ``` ## Meta Description Formula **40-60 words. Include:** 1. Primary keyword (first 10 words) 2. Clear value proposition or unique angle 3. A statistic, number, or specific detail 4. Call to action or benefit **Formula:** ``` [Topic] explained: [Key benefit/finding]. [Statistic or specific detail]. [What reader will learn/get]. [CTA or timeframe]. ``` **Example:** ``` GEO (Generative Engine Optimization) boosts AI citation visibility by 115%. Learn the 5 core techniques that get your content cited by ChatGPT, Perplexity, and Claude — with implementation guides for any platform. ```
